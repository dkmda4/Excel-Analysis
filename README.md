# 📊 Excel Data Analysis Portfolio

## 📌 Project Overview

This project showcases practical Excel skills developed through structured data technician training exercises.
The workbook covers core spreadsheet techniques used in real-world data roles, including data cleaning, aggregation, pivot tables, logical functions, and basic analysis for business reporting.

The focus is on using Excel not just as a calculator, but as a data analysis and decision-support tool.



## 📂 Data Sources

Multiple small datasets were used across the workbook, including:

	•	Retail sales dataset (commission, age, transactions)
	•	Bike sales dataset (markets, demographics, profit)
	•	County-level product sales dataset
	•	Simulated customer and product data

All datasets are structured in tabular format and designed to replicate common business scenarios.

### 3. 🔍 Lookup Functions (VLOOKUP vs XLOOKUP)

This project demonstrates the use of both VLOOKUP and the modern XLOOKUP function to retrieve related information across tables, simulating real-world relational data tasks.
Lookup functions are essential in analytics workflows for joining customer, transaction, and reference data without physically merging datasets.

<img width="385" height="20" alt="image" src="https://github.com/user-attachments/assets/527d0998-741a-4813-80c5-732cfd8ab3cf" /> <br>
<img width="415" height="85" alt="Screenshot 2026-02-04 at 23 05 50" src="https://github.com/user-attachments/assets/5533724a-5a13-4aca-b2d8-9ce0d95ffd05" /> <br>


What this does:
Returns the customer’s gender by matching a Customer ID from the input cell against a reference table, with a fallback message if no match is found.

Why this matters analytically:

	•	Enables relational-style data linking without merging tables
	•	Uses structured references for maintainability
	•	Includes built-in error handling
	•	Supports dynamic models where source data changes
